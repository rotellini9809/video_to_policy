========================================================
GIT WORKFLOW (LEGGERE CON ATTENZIONE O SI CREANO CASINI)
========================================================


--------------------------------------------------------
REGOLE D'ORO
--------------------------------------------------------

- Il repo padre NON salva i file del submodule,
  salva SOLO il commit hash (puntatore)

- "HEAD detached" nel submodule = stato normale dopo submodule update.
  In quello stato: NON committare.

- Se devi lavorare nel submodule (commit/push):
  attaccati SEMPRE a main (git switch/checkout main)

- Obiettivo di questo workflow:
  mjlab deve stare SEMPRE al latest del TUO fork (origin/main)


--------------------------------------------------------
SETUP (UNA SOLA VOLTA): submodule traccia main
--------------------------------------------------------

Nel repo padre (video_to_policy) in .gitmodules deve esserci:

[submodule "mjlab"]
  path = mjlab
  url = https://github.com/rotellini9809/mjlab.git
  branch = main

Poi esegui:

cd video_to_policy
git submodule sync --recursive
git add .gitmodules
git commit -m "mjlab tracks main"
git push


--------------------------------------------------------
PUSH DEL SUBMODULE (mjlab - fork)
--------------------------------------------------------

cd video_to_policy/mjlab

# ATTACCATI SEMPRE A MAIN (mai committare in detached)
git switch main || git checkout main
git pull --ff-only

# commit delle modifiche
git add .
git commit -m "Describe your change"

# push sul TUO fork
# usare force-with-lease se il fork è stato force-pushato in passato
git push --force-with-lease origin main


--------------------------------------------------------
PUSH DEL REPO PADRE (video_to_policy)
--------------------------------------------------------

# PRIMA pushare SEMPRE il submodule

cd .. (video_to_policy)

# il repo padre salva SOLO il puntatore al submodule
git add mjlab
git commit -m "Update mjlab submodule"
git push


--------------------------------------------------------
PULL CORRETTO (mjlab SEMPRE ALL'ULTIMO COMMIT DEL TUO FORK)
--------------------------------------------------------

cd video_to_policy

# aggiorna il repo padre
git pull

# aggiorna mjlab al latest del branch configurato (main sul fork)
git submodule update --init --recursive --remote --merge mjlab

# evita detached se poi devi lavorare/subito committare nel submodule
git -C mjlab switch main || true
git -C mjlab pull --ff-only || true
