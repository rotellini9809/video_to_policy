========================================================
GIT WORKFLOW (LEGGERE CON ATTENZIONE O SI CREANO CASINI)
========================================================


--------------------------------------------------------
REGOLE D'ORO
--------------------------------------------------------

- NON committare MAI in un submodule se vedi:
  "HEAD detached"

- Prima di modificare un submodule:
  git checkout main

- Il repo padre NON salva i file del submodule,
  salva SOLO il commit hash (puntatore)

- I conflitti con l'upstream si risolvono DOPO,
  non durante il lavoro quotidiano


--------------------------------------------------------
PUSH DEL SUBMODULE (mjlab - fork)
--------------------------------------------------------

cd video_to_policy/mjlab

# ATTACCATI SEMPRE A MAIN
git checkout main

# commit delle modifiche
git add .
git commit -m "Describe your change"

# push sul TUO fork
# usare force-with-lease se il fork è stato force-pushato in passato
git push --force-with-lease origin main


--------------------------------------------------------
PUSH DEL REPO PADRE (video_to_policy)
--------------------------------------------------------

# PRIMA pushare SEMPRE il submodule

cd video_to_policy

# il repo padre salva SOLO il puntatore al submodule
git add mjlab
git commit -m "Update mjlab submodule"
git push


--------------------------------------------------------
PULL CORRETTO (NON fare pull nei submoduli)
--------------------------------------------------------

cd video_to_policy

# aggiorna il repo padre
git pull

# aggiorna SOLO il submodule che serve
git submodule update --init --recursive mjlab


--------------------------------------------------------
CASO SPECIALE: ALTRO PC / FORK FORCE-PUSHATO
--------------------------------------------------------

Se sei DENTRO un submodule e vuoi solo allinearti
al TUO fork (senza integrare upstream):

cd video_to_policy/mjlab
git fetch origin
git checkout main
git reset --hard origin/main


--------------------------------------------------------
RIASSUNTO MENTALE (STAMPALO IN TESTA)
--------------------------------------------------------

- Modifico submodule  -> commit + push nel submodule
- Poi repo padre      -> commit del puntatore
- Pull                -> SOLO dal repo padre
- Submodule update    -> SOLO con git submodule update
- HEAD detached       -> NON committare
